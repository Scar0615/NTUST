# 隱私資訊安全 (Privacy & Information Security)

隱私與資訊安全課程作業與期末專題。

- `hw1/` — k-匿名化(Mondrian algorithm),使用 UCI Adult Dataset
- `group12_hw2/` — 差分隱私合成資料(Differentially Private Synthetic Data)
- `Group12_hw3/` — 人臉去識別化(pixelate / blur 等隱私保護技術)
- `Group12_Midterm/` — 差分隱私深度學習(DP-SGD)
- `final project/` — 聯邦學習(Federated Learning)、梯度洩漏攻擊(Gradient Leakage Attack)與防禦(差分隱私 / 同態加密)
